# ADR-0005: 開放コンテンツ方針

- Status: Accepted
- Date: 2026-09-28

## Context

公式 Instruct モデルによるクエリの言い換え・回答拒否と、検索プロバイダの既定 safesearch により、合法なセンシティブな調査が途中で失われることがある。Tavily の Acceptable Use Policy は性的に露骨な利用を禁じている。

## Decision

既存の検索 → ページ取得 → システムプロンプトへの注入 → 出典表示を維持し、四層で扱う。

1. 入力: 未成年者の性的内容の明確な要求だけを、検索と画像プロンプト処理の前に拒否する。
2. 検索: 開放モードでは safesearch を既定で off とし、Brave → DuckDuckGo → Tavily の順で選ぶ。標準では moderate と従来の選択順にする。
3. クエリ: 話題を変えない書き換え指示を使い、拒否・空・無関係な書き換えは元の質問に戻す。
4. 回答: 開放モードの方針を Chat のシステムプロンプトに追加し、取得したページに番号付き出典を付ける。

## Consequences

- 検索クエリは外部プロバイダへ送信される。開放モードでは成人向けの話題も含み得る。
- Tavily が唯一利用可能、または明示選択された場合は警告を表示する。Tavily の利用規約を回避する処理は加えない。
- 公式 Instruct モデル自体の拒否は残り得る。モデルの差し替えは設定で対応する。
