# ADR-0004: Web検索（リアルタイム情報）

- Status: Accepted
- Date: 2026-09-28

## Context
Qwen3.8-27B の知識は学習データの期限まで（ユーザー報告では 2026/4 頃まで）。最新情報を聞くと古い回答になる。

## Decision
- Chat の前段に **検索 → 本文取得 → 出典付きコンテキスト注入** を追加（ツール呼び出し型エージェントではなく、決定的な RAG パイプライン）
- 検索するかどうかは UI の 自動 / 常に / オフ。自動はキーワード判定（最新・今日・ニュース・年号・調べて 等）
- クエリは Chat モデルが会話文脈と今日の日付から作成（失敗時は元の文をそのまま使用）
- プロバイダは Tavily → Brave → DuckDuckGo（`ddgs`, キー不要）の順で自動選択
- 検索しないときもシステムプロンプトに現在日時を入れる

## Consequences
- 👍 追加の GPU メモリ不要。L4 でも同じ Chat モデルで動く
- 👍 回答末尾に出典リンクが残り、履歴（`messages.meta.web_search`）にもクエリとURLが残る
- 👎 自動判定はキーワード依存（漏れたら「常に」に切替）
- 👎 DuckDuckGo 経由はレート制限・ブロックがあり得る → 安定させたい場合は Tavily/Brave のキー
- 👎 検索クエリが外部サービスに送信される（README Security に明記）
